# 브로우 아카이브 빌더

반영구 눈썹 시술자를 위한 랜딩페이지 빌더입니다.
내용을 채우면 전환 구조가 잡힌 페이지가 만들어지고, 만들어진 파일을 무료 호스팅에 올리면 그대로 공개됩니다.

설치할 것이 없습니다. `index.html` 하나가 전부이고 브라우저에서만 동작합니다.
서버도, 빌드도, 계정도 필요하지 않습니다.

---

## 올리는 법

1. 깃헙에서 새 저장소를 만듭니다. (Public)
2. 이 폴더의 파일을 저장소 최상단에 올립니다. `.nojekyll` 도 빠뜨리지 마세요.
3. **Settings → Pages → Source** 를 `Deploy from a branch`, 브랜치를 `main` / `(root)` 로 지정합니다.
4. 1–2분 뒤 주소가 열립니다.

저장소 이름을 `내아이디.github.io` 로 만들면 주소가 `https://내아이디.github.io` 가 되고,
다른 이름이면 `https://내아이디.github.io/저장소이름` 이 됩니다.

### `.nojekyll` 이 필요한 이유

깃헙 페이지는 기본적으로 Jekyll 로 파일을 한 번 처리합니다.
그 과정에서 밑줄로 시작하는 파일과 폴더가 무시되고, 빌드가 실패하면 페이지 전체가 올라가지 않습니다.
이 파일 하나를 두면 깃헙이 파일을 건드리지 않고 그대로 내보냅니다.

## 쓰는 법

왼쪽이 편집 패널, 오른쪽이 실시간 미리보기입니다. 화면이 좁으면 위쪽 **편집 / 미리보기** 탭으로 전환됩니다.

- **챕터 순서** — 손잡이(⣿)를 끌거나 ↑↓ 버튼으로 바꿉니다
- **챕터 켜고 끄기** — 스위치를 끄면 페이지에서 그 섹션이 통째로 사라집니다
- **챕터 제목** — 각 챕터 첫 칸에서 원하는 말로 바꿉니다
- **톤** — 배경색과 글자색 두 개만 정하면 본문색, 선, 흐린 글씨가 그 사이에서 자동으로 만들어집니다

### 내보내기 두 가지

| 방식 | 결과 | 어디에 쓰나 |
|---|---|---|
| **페이지 내려받기** | `index.html` 한 개 (사진 포함) | Netlify Drop 처럼 파일 하나로 끝낼 때 |
| **깃헙용 폴더** | ZIP (사진이 `assets/` 로 분리) | 깃헙 페이지에 올릴 때 |

깃헙용 폴더 쪽이 빠릅니다. 사진이 파일로 나뉘면 브라우저가 각각을 캐시에 남기기 때문에,
두 번째 방문부터는 글만 새로 받습니다.

**설정 저장** 으로 받아둔 `landing-settings.json` 을 보관하세요.
나중에 **불러오기** 로 열면 이어서 고칠 수 있습니다. 이 파일이 없으면 처음부터 다시 채워야 합니다.

## 만들어지는 페이지의 구조

섹션 순서는 그대로 설득 순서입니다.

1. **표제** — 사진이 위, 글이 아래. 광고에서 쓴 단어를 제목에 그대로 넣어야 이탈이 줄어듭니다
2. **망설임** — 문제를 고객의 말 그대로 적고 시술 방식으로 답합니다
3. **시술자** — 고객은 업체가 아니라 사람과 예약합니다
4. **작업 기록** — 좌우로 미는 전후 비교. 시술별 필터는 여기에만 둡니다
5. **받은 말** — 별점 대신 문장과 서명줄
6. **가격** — 금액을 숨기면 문의는 늘지만 실제 예약은 줄어듭니다
7. **진행 순서** — 처음인 사람의 불안을 없앱니다
8. **질문** — 통증, 유지 기간, 기존 시술 커버, 회복 기간 네 가지는 반드시
9. **마무리** — 예약보다 문턱이 낮은 행동을 앞에 둡니다

시술별 탭을 맨 위에 두지 않는 것이 이 빌더의 기본 원칙입니다.
눈썹을 보러 들어온 사람에게 첫 화면에서 선택을 시키면 이탈이 늘어납니다.
필터는 이미 관심이 붙은 작업 기록 안에 두어, 클릭이 이탈이 아니라 몰입 신호가 되게 합니다.

## 담긴 파일

```
index.html     빌더 전체 (HTML · CSS · JS 한 파일)
.nojekyll      깃헙이 파일을 건드리지 않게 하는 표시
robots.txt     검색 로봇 안내
.gitignore     저장소에 올리지 않을 것들
LICENSE        MIT
README.md      이 문서
```

바깥에서 받아오는 것은 구글 폰트(IBM Plex Sans KR · IBM Plex Mono)뿐입니다.
사진은 브라우저 안에서만 처리되고 어디로도 전송되지 않습니다.

---

## 브라우저

크롬, 사파리, 엣지, 파이어폭스 최신 버전에서 동작합니다.
사진 처리에 Canvas, 내려받기에 Blob 을 쓰기 때문에 인터넷 익스플로러에서는 열리지 않습니다.
